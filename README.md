# NOVARA — website

Lavender & Coral "Blueprint" design for an architecture + interiors studio.
React 19 · Framer Motion · Lenis smooth scroll · Vite. Fonts are self-hosted (Archivo variable, IBM Plex Mono, Architects Daughter).

## Run it

```bash
npm install
npm run dev        # local dev server at http://localhost:5173
npm run build      # production build into dist/
npm run preview    # serve the build locally
```

Deploy: upload `dist/` to any static host (Vercel, Netlify, Cloudflare Pages, S3). Paths are relative, so it also works from a sub-folder.

    Footer.jsx         ← pen-plotter wordmark

    Room.jsx           ← the room, modelled in metres; every solid carries its line-drawing edges

## Change the colours

Edit the variables at the top of `src/styles.css` (`--plum`, `--lav`, `--coral`, …).

## 3D hero

The hero loads a WebGL room after first paint. It falls back to the photo/drawing hero when reduced motion is on,
WebGL2 is missing, on phones with ≤ 4 cores, or when the first 60 frames average under 40 fps.
For testing: `?no3d` forces the fallback, `?force3d` skips the device checks and the fps probe.

## Photography

All photos are free Unsplash License images (see `scripts/credits.json`, credited in the footer). To swap one:
put the new original at `scripts/raw/<slot>-<id>.jpg`, change the id in `SLOTS` in `scripts/process-images.mjs`, then run

```bash
node scripts/process-images.mjs            # every slot
node scripts/process-images.mjs hero       # just one
```

## Before launch

- Replace sample names, figures and prices in `src/data.js`.
- Connect the enquiry, RFI and newsletter forms to your email/CRM (they currently only show the confirmation stamp).
- Everything respects `prefers-reduced-motion`; smooth scroll switches off automatically for those users.

## Shared state and the enquiry

- `src/store/brief.js` — what the visitor builds on the way down: the Materials palette, the Fees scope and an FAQ
  question. Contact shows each as its own removable line and on the live sheet.
- `src/store/calm.js` — Calm mode (nav lamp button). Defaults to the OS reduce-motion setting, remembered in
  localStorage; turns off Lumen, the 3D hero, cursor effects, Lenis and all non-essential motion.
- `src/lib/submitEnquiry.js` — **the one place an enquiry leaves the site.** It currently resolves after 800 ms;
  see the TODO there to connect it to email.
